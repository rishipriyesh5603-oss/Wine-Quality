# Wine-Quality
Wine Quality Prediction App using Machine Learning and Streamlit.

Wine Quality Prediction App:

A Machine Learning web application built using Streamlit that predicts whether a wine is of Good or Bad quality based on its chemical properties.

Project Overview:

This project uses a trained Machine Learning model to classify wine quality.
Users can input chemical features such as acidity, alcohol, pH, etc., and the model predicts the quality instantly.

Features Used:

1) Fixed Acidity
2) Volatile Acidity
3) Citric Acid
4) Residual Sugar
5) Chlorides
6) Free Sulfur Dioxide
7) Total Sulfur Dioxide
8) Density
9) pH
10) Sulphates
11) Alcohol
